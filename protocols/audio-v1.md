# Audio v1 / firmware+SDK V0.5.0 implementation contract

PCM wire: `format="pcm_s16le"`, sample_rate=16000, channels=1, sample_width=2, byte_order=little. WAV is a PC file container, never send its header as PCM. Local/cloud sources produce identical AudioClip. Existing cloud_server accepts raw 16k/16bit/mono bytes at dialogue and uses little-endian in providers. Do not infer endian from legacy audio/L16 MIME; explicit metadata wins. No AI server work.

All audio RPCs require the owning session. `audio.info` and status fields public. max chunk=768 decoded bytes, even byte counts; JSONL remains4096. Audio I2S runtime mapping is session-scoped, not NVS. Configuration survives maintenance/config.apply/outputs.stop within the session, clears at session.close/lease expiry. No audio at boot. One shared BCLK/WS, independent mic din and amp dout, half-duplex RPC recording/playback. No MCLK/PDM/analog-mic support this slice.

`audio.configure {bclk,ws,din,dout,sd,mic_channel,volume}` requires maintenance. bclk/ws valid output GPIO; din input or-1, dout output or-1, sd output or-1, at least one data direction; mic_channel left/right; volume0..100. All assigned pins unique; conflicts with system/display/servos/GPIO rejected before publication. SD optional module shutdown. Configuration releases active audio before replacement; no NVS write for audio spec. returns configured=true and canonical fields+PCM metadata. SDK audio.set same args defaults42/41/21/40/39,left,20, enters maintenance and callsconfigure. Further display/servo config must also reject conflicts with current audio session mapping.

`audio.begin {}` requires nonmaintenance and configured; Hardware.beginAudio(spec); starts clocks, leaves amp muted, no capture/playback initiated. idempotent when active, returns active,configured,PCM metadata. SDK robot.start() starts requested display+audio after allsets, never starts audio transmission/recording or servo motion.

`audio.record.begin {}` requires audio active+din>=0 and neither recording nor playing; Hardware.startAudioCapture() flushes bounded old RX; starts record counter0. `audio.read {bytes}` even2..768, only recording; Hardware.readAudio(uint8_t*,size_t) returns exact count or firmware HARDWARE_ERROR, data base64 PCM bytes,bytes,offset of first byte; increments only on success. `audio.record.end {}` calls Hardware.stopAudioIO() to leave HAL capture mode, returns bytes/samples, clears recording; no I2S teardown needed. SDK record(seconds) requests exact rounded sample count, returns AudioClip on PC and stops capture even errors; no partial-success claim.

`audio.play.begin {}` requires active+dout>=0, neither mode active; Hardware.startAudioPlayback() enables amp, starts counter0. `audio.write {offset,data}` strictbase64<=768 evenbytes, exactoffset; Hardware.writeAudio(const uint8_t*,size_t) exact count orerror; volume applied HAL; returns bytes,next_offset. `audio.play.end {}` Hardware.finishAudioPlayback() writes bounded silence to drain prior queued samples and mutes amp, returns bytes/samples, playing=false. `audio.stop {}` Hardware.stopAudioIO() mutes amp/cancels active capture/play flags, keeps configured activebus for reuse, resets counters; allowed maintenance. No automatic replay/retry. Audio write/read hardware failures attempt stopAudioIO and clear mode, report failure.

`audio.release {}` releases hardware+mode, retains runtime mapping/reservations; `audio.unconfigure {}` also drops mapping. Both allowed maintenance, idempotent. Every stopOutputs path must releaseAudio and clear stream flags, while keeping mapping until session close/expiry. If hardware cleanup fails report driver_ok=false and HARDWARE_ERROR; do not clear active flag on failedrelease. On close/expiry mapping only cleared after successfulrelease, so failed cleanup retains ownership to prevent GPIO reuse. Nextsession can release/unconfigure or retrycleanup.

audio.info/status.audio fields: configured,active,driver_ok,recording,playing,read_bytes,written_bytes,format,sample_rate,channels,sample_width,byte_order; if configured add canonical pins,mic_channel,volume. capabilities audio_in/audio_out/i2s_audio/configurable_audio_pins=true, full_duplex_audio=false; limits.audio_chunk_bytes=768. Pins list adds digital_input/digital_output/analog_input/analog_output(false)/pwm_output and audio owner. Distinguish ADC vs PWM (not true DAC); S3 profile has no enabled analog-output/DAC.

Pin listing compatibility: capabilities.pin_pagination=true. pins.list{} retains all45legacy pinitems without the5newflags, so oldSDKresponses remain<4096bytes. NewSDK requests pins.list{offset:0,limit:12} and follows next_offset(int|null); resultalsooffset,total45,pins. Pageditemsinclude5newflags. Bounds offset0..45 andlimit1..12, strictint; offset45 returns emptyfinal. SDKassemblespages, validatesprogress/total/duplicatepins, no retries. This avoids an8347byte response overflowing the originalJSONL receiver.

HAL interfaces in Hardware (root adds todevice_core.h):
`bool beginAudio(const AudioSpec&)`, `bool startAudioCapture()`, `size_t readAudio(uint8_t*,size_t)`, `bool startAudioPlayback()`, `size_t writeAudio(const uint8_t*,size_t)`, `bool finishAudioPlayback()`, `bool stopAudioIO()`, `bool releaseAudio()`.
BoardAudio class matches begin(spec),startCapture(),read(data,bytes),startPlayback(),write(data,bytes),finishPlayback(),stopIO(),release(). Shared 16000Hz I2S standard stereo32 hardware slots. RX selectedL/R top16 bits -> mono PCM16LE. TX PCM16LE signextend/gain -> both stereo32 slots. Explicit bounded read/write timeouts<=250ms and no blocking seconds-long audio command, preserve6s lease. Amp SD heldlow unless playing; release must setSDlow/endI2S and release only ownedGPIO. If noSD GPIO, silence/disableI2S cannot promise physical amp poweroff.

SDK public audio module: AudioClip(pcm bytes + fixedmetadata), from_wav/to_wav, from_pcm/to_pcm, to_wire/from_wire metadata bridge; read localWAV/PCM and explicitHTTP audio URL into same AudioClip; bound sizes and validate format/rate/channels/width before hardware playback. Never guess MP3/OGG bytes as PCM. robot.audio.set/begin/info/record/play/play_file/play_url/stop/release/unconfigure. Package all neededcode under ai_robot; portableexamples import ai_robot directly, no projectroot sys.path or _board. OptionalTurtle publicentry should also be packaged without breaking existing localwrapper tests. SDK version0.5.0, firmware0.5.0. Currentboard remains1MiB application partition; no merged flash.
