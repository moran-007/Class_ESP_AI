# 代码内配置与最小示例

SDK0.4.1新增更短的display.set/servo.set及统一start，支持按屏幕丝印写SCL/SDA/RES/BLK；也支持位置参数。无with和多设备示例详见 [set接口与刷新帧率](set接口_丝印对照与刷新帧率.md)，下文原configure写法仍支持。

推荐学员直接在当前Python文件中写串口与IO，按“连接 → 配置 → 动作”的顺序阅读。无需先编辑JSON或使用配置窗口。当前教学固件V0.4.0不变，不需要重新烧录。

## 1. 串口写一行

在 `tests/guide/` 中新建Python文件：

```python
from _board import connect

with connect("COM5") as robot:
    print(robot.get_info())
```

把COM5改为自己的实际串口，例如COM6。`connect("AUTO")`只在唯一USB串口时自动选择；不依次探测所有串口。进入with才打开串口，结束自动关闭并释放会话。无需学员自己写心跳线程或串口JSON。

普通SDK独立使用时，写 `with Robot(port="COM5") as robot:`；`Robot`第一个位置参数是连接类型，不要写成 `Robot("COM5")`。课程辅助入口 `connect("COM5")`专门接受串口作为第一个参数。

## 2. LED：配置一个IO

```python
from _board import connect

with connect("COM5") as robot:
    robot.maintenance.exit()
    robot.gpio.setup(pin=12, mode="output")
    robot.gpio.write(pin=12, value=1)
    robot.wait(3)
```

外接LED串合适的限流电阻接GPIO12和GND；修改两处pin即可换脚。运行表示已完成接线，退出维护后才执行输出。结束自动释放信号；已启用的默认屏幕页随后恢复。板载RGB使用 `robot.led`，不需要指定GPIO48。

## 3. 按钮控制LED：输入输出各一脚

```python
from _board import connect

with connect("COM5") as robot:
    robot.maintenance.exit()
    robot.gpio.setup(pin=2, mode="input_pullup")
    robot.gpio.setup(pin=12, mode="output")
    for _ in range(30):
        pressed = robot.gpio.read(pin=2) == 0
        robot.gpio.write(pin=12, value=int(pressed))
        robot.wait(0.5)
```

按钮接GPIO2与GND，按下读0。LED输出1时点亮，所以使用 `int(pressed)` 转成1/0。GPIO是板上标注的IO号，不是排针位置序号。

## 4. 舵机：命名参数指定IO和校准

```python
from _board import connect

with connect("COM5") as robot:
    robot.servo.configure("test", pin=14, min_angle=30, max_angle=150,
                          min_pulse_us=1000, max_pulse_us=2000)
    robot.maintenance.exit()
    robot.servo.move("test", 90)
    robot.wait(3)
```

当前SG90预设，先完成匹配的独立供电、共地，首次卸下连杆。配置仅保存映射并保持维护；move才发送动作。舵机校准参数在舵机实验中介绍，普通LED实验无需学习它们。关闭会话撤销脉冲，不切断舵机电源。

## 5. 屏幕：一组命名参数填写全部信号

```python
from _board import connect

with connect("COM5") as robot:
    robot.display.configure(panel="st7735s_128x160", sck=4, mosi=5,
                            cs=15, dc=7, rst=6, backlight=16, rotation=1)
    robot.maintenance.exit()
    robot.display.begin()
    robot.display.text("你好，创客！", x=8, y=8)
    robot.wait(10)
```

支持 `st7735s_128x160`、`st7789_240x320`、`st7789_240x240`。无GPIO控制BLK时填 `backlight=-1`。反相和亮度省略时SDK按型号/有无BLK选择默认值，也可显式传 `invert=True`、`brightness=60`。

屏幕完整示例的配置、初始化步骤适合首次学习。熟悉后可以用课程辅助简写：

```python
from _board import connect_screen

with connect_screen("COM5", panel="st7735s_128x160",
                    sck=4, mosi=5, cs=15, dc=7, rst=6, backlight=16) as robot:
    robot.display.text("你好，创客！", x=8, y=8)
    robot.wait(10)
```

`connect_screen`会保存屏幕映射、退出维护并begin；运行前先完成接线。显式IO参数直接交给SDK，不与JSON接线混合；未写出的参数使用SDK默认值。改线先进入维护、断电，不能只改代码而不改接线。

## 6. Turtle也在当前文件配置

在普通标准库turtle绘图之后，用：

```python
finish(screen, port="COM5", panel="st7735s_128x160",
       sck=4, mosi=5, cs=15, dc=7, rst=6, backlight=16)
```

完整文件见 [10_turtle.py](../tests/guide/10_turtle.py)。绘图不打开USB；点击发送或Enter才连接、配置并初始化屏幕；关闭窗口才释放会话，恢复已启用的默认页。图片依赖Pillow，Turtle依赖Tcl/Tk。

## 7. 主示例与可选统一配置

| 入口 | 配置来源 |
|---|---|
| `tests/guide/`，根目录 `运行示例.cmd` | 推荐。COM与IO直接写在每个文件的函数调用中 |
| `connect("COM5")` | 只使用指定串口，不读统一JSON |
| `connect_screen("COM5", panel=..., sck=..., ...)` | 指定串口和外设参数，不读统一JSON |
| `connect()` | 兼容旧代码，读取统一JSON中的串口 |
| `connect_screen()` | 兼容旧代码，读取统一JSON中的串口和屏幕映射 |
| `tests/guide_shared/` | 保留的统一配置版示例，适合进阶集中管理 |
| `配置硬件.cmd`、页面编辑器 | 可选统一配置窗口及网页页面制作工具 |

统一配置的 `PORT/PINS/SERVO/SCREEN` 只在显式导入时读取。代码内配置无需JSON文件存在或有效，也不会被其中的IO参数覆盖。但板上已经保存的其他外设映射仍有资源约束，冲突可通过 `list_pins()` 查看。

全部参数、返回结果与错误：[SDK函数手册](SDK函数说明与示例_V0.4.md)。可选统一配置：[统一配置说明](统一配置与接线说明.md)。
