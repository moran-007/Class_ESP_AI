# 屏幕测试与自定义引脚 V0.3

> 配置入口已统一：使用项目根目录 `配置硬件.cmd` 或 `config/hardware.json`。旧settings.py和_screen_settings.py只作兼容读取；下文相关旧配置操作以 `docs/统一配置与接线说明.md` 为准。

本说明对应教学固件和Python SDK 0.3.0，协议仍为v1，不依赖AI服务器。一个固件支持以下屏幕；更换屏幕型号或信号引脚通过配置完成，不需要每次重新烧录。

## 1 支持的屏幕

| 屏幕 | PANEL | BACKLIGHT |
|---|---|---|
| 7针ST7789 / M200T，240×320 | `"st7789_240x320"` | `-1`，模块内部供电，没有独立BLK |
| 8针ST7789，240×320 | `"st7789_240x320"` | BLK接GPIO时填写该GPIO；固定接电源则`-1` |
| 8针ST7735S，128×160 | `"st7735s_128x160"` | BLK接GPIO时填写该GPIO；固定接电源则`-1` |
| ST7789，240×240 | `"st7789_240x240"` | 按实际BLK接线填写 |

ST7735S采用与原AI项目相同的BLACKTAB初始化；ST7789按原生尺寸初始化。8针ST7789与ST7735S可以使用相同的信号排针顺序，但控制器初始化和分辨率必须正确。按模块丝印连接，不能仅靠针脚位置判断。屏幕标为SDA的是这里的SPI MOSI，接口并非I²C。

## 2 所有信号引脚都可自定义

只修改 `tests/quick/_screen_settings.py`：

```python
PANEL = "st7789_240x320"
SCK = 4
MOSI = 5
CS = 15
DC = 7
RST = 6
BACKLIGHT = -1  # 无BLK用-1；若BLK接GPIO16则填16
ROTATION = 1
INVERT = None
BRIGHTNESS = None
```

以上GPIO仅为原项目参考值，**SCK、MOSI、CS、DC、RST、BLK均没有固定在这些引脚上**。请替换为自己的实际接线。模块VCC/GND按规格供电并与ESP32共地，GPIO采用3.3V逻辑。BLK若是直接LED电源端而非受控逻辑输入，需按模块额定电流使用合适驱动，不把未知背光负载直接交给GPIO供电。

当前保守N16R8板型限制启动、USB、UART、Flash/PSRAM与板载RGB引脚。不能将屏幕接到保留脚，多个信号不可重复，也不可与已保存的舵机映射重叠。实际能力与占用可运行 `01_device_info.py` 查看；屏幕配置生效后其信号脚owner为display，即使暂未初始化也保留给屏幕。

`ROTATION`为0～3：0/2竖屏，1/3横屏；ST7789 240×320横屏返回320×240，ST7735S横屏160×128。`INVERT=None`自动选择ST7789反相、ST7735不反相；若实际颜色整体反相，可明确填True或False，不改变颜色名称掩盖控制器差异。

`BRIGHTNESS=None`默认有GPIO背光60%，无GPIO背光100%。有BLK可设0～100；没有BLK时不能进行PWM调光，接口会明确报不支持，不通过改像素冒充硬件背光。

## 3 测试顺序

1. 关闭其他串口程序，断电完成接线、型号与公共配置修改。
2. 使用固件0.3.0和SDK0.3.0；本机新源码与项目虚拟环境见主README。仅修改引脚不需要更新固件。
3. 运行 `tests/quick/screen_colors.py`，或双击根目录 `运行屏幕测试.cmd`：依次红、绿、蓝、白、黑，每色两秒，检查满屏范围和颜色顺序。
4. 运行 `tests/quick/screen_text.py`：显示英文、中文、RGB自定义色矩形和线段，保持十秒，检查方向、裁切和文字。
5. BLK确实接GPIO时，运行 `tests/quick/screen_backlight.py`：20%、60%、100%、60%逐档变化。BLK缺省-1时该脚本不连接设备，直接提示未配置背光。

`开始测试.cmd`菜单也提供以上三项。每个测试8～12行，点击运行即可，无需命令行参数。连接默认沿用 `tests/quick/settings.py` 的唯一USB串口自动选择；多个候选时显式填写端口。

新文件首次运行会保存SCREEN配置、进入并退出维护、显式初始化屏幕。运行表示已经核对实际接线。它保留其他舵机映射，但进入维护会停止已有会话输出。换屏或换线前进入维护并确认停止，再断电操作，不能在SPI刷新中插拔杜邦线。

## 4 自己写屏幕程序

文件保存在 `tests/quick/`：

```python
from _screen import connect_screen

with connect_screen() as robot:
    robot.display.fill("black")
    robot.display.text("你好，创客！", x=10, y=10, color="white")
    robot.display.rect(10, 40, 100, 30, color=(55, 88, 99), filled=True)
    robot.wait(5)
```

颜色支持名称black/white/red/green/blue/yellow/cyan/magenta、RGB三元组0～255、RGB565整数0～65535。屏幕RGB三元组与板载灯接口的0～32分量限幅是不同接口。

文字使用内置文泉驿12px GB2312字体，支持常用中文、英文与数字；不是全部Unicode字库。坐标以当前旋转后的屏幕左上角为原点；换行使用`\n`、行高16，不自动折行。每次文字最多192个UTF-8字节；超出画面的字形被裁切，不会自动缩小。

可用方法：`configure()`、`begin()`、`fill()`、`clear()`、`text()`、`rect()`、`line()`、`brightness()`、`release()`、`unconfigure()`。完整参数见 [SDK说明](../sdk/python/README.md) 与 [协议合同](../protocols/display-v1.md)。

高级用法中configure只保存映射并保持维护，不初始化屏幕：

```python
from ai_robot import Robot

with Robot() as robot:
    robot.display.configure("st7735s_128x160", sck=4, mosi=5, cs=15, dc=7, rst=6, backlight=16)
    robot.maintenance.exit()
    robot.display.begin()
    robot.display.fill("blue")
    robot.wait(5)
```

## 5 退出、资源与固件更换

当前仍沿用会话退出策略：停止、关闭、超时或进入维护时关闭显示、停止背光PWM、释放SPI及控制引脚，配置保留。屏幕不会在重启或退出维护后自动启动；画面保持多久由`with`内等待决定。当前没有默认程序接管/恢复流程。

一个受GPIO控制的BLK使用LEDC通道3，普通PWM可用配额从4降至3；四路舵机配额不变。BLK为-1时普通PWM仍4。SPI当前由这个屏幕独占，未实现与SD等设备共享总线。

V0.3读取旧版舵机配置时不会自动初始化外设。保存了display配置后，旧V0.2固件不认识该字段；降级前先调用 `robot.display.unconfigure()` 并确认保存，或恢复匹配的NVS备份。不要直接清空整个NVS处理兼容问题。

当前板已有factory分区大小1MiB；构建仍生成16MiB参考分区的合并镜像，**当前板仅更新应用文件，不用merged.bin覆盖现有分区**。新增中文字库扩大了应用，刷写前已要求扩展原应用备份与升级前NVS备份；实际刷写与测试状态以 [验证记录](verification.md) 为准。私有备份不作为公开分发文件。

## 6 结果如何判断

2026-11-09用户已确认本次测试“纯色、满屏范围和中文都正常”，这三项已记录为通过。回复未逐项注明屏幕型号与背光调光结果，因此其他型号及背光仍按各次实际测试单独记录，详见 [验证记录](verification.md)。

驱动通过SPI发送命令，未接MISO，不具备模块在场或图像识别反馈。`state=commanded, physical_verified=false`只表示软件执行命令，不能证明屏幕已接好、实际点亮、颜色/方向正确。无屏连接时也可能得到正常回执。

| 现象 | 优先检查 |
|---|---|
| 背光亮但无图 | PANEL/分辨率、SCK/MOSI、CS/DC/RST、供电和共地 |
| 完全不亮 | VCC/GND、BLK是否需要供电、BACKLIGHT是否与实际相符 |
| 颜色反相或异常 | PANEL、INVERT、原色测试；保留实际现象用于继续判断 |
| 显示偏移、裁切 | 型号/尺寸和ROTATION；ST7735初始化标签差异需据具体模块调整 |
| CONFIG_INVALID | 保留脚、重复脚、舵机冲突、无BLK却设置非100亮度 |
| RESOURCE_CONFLICT | 该GPIO已保留给屏幕/舵机；或BLK占用后普通PWM配额不足 |
| MAINTENANCE_REQUIRED | 高级接口尚未显式退出维护；先检查接线与配置 |
| 旧固件不支持display | 升级屏幕固件0.3.0；不要只更新Python文件 |

屏幕实际测试请分别记录型号、接线、颜色、满屏范围、中文和背光；一块屏正常不代表其他模块已经实测。
