# 屏幕固化、清除与恢复原页面

本测试只驱动屏幕，不移动舵机或启用音频。需要教学固件/SDK0.6.0；默认屏幕为ST7735S128×160、rotation=1，接线4/5/15/7/6/16，信号顺序见 [测试目录](../tests/standalone/README.md)。

## 运行哪个文件

1. 运行 [screen_save.py](../tests/standalone/screen_save.py)。程序配置的是Program自己的屏幕快照，保存后关闭连接，不替换原页面模板。
2. 按RESET或重新接电：应看到深蓝“固化屏幕A / standalone A”和深绿“固化屏幕B / standalone B”，每4秒交替；横条分别为青色与黄色。
3. 观察时不要运行另一个Robot脚本。电脑取得会话会停止固化并接管，这是继续开发的入口，不是固化失效。
4. 运行 [screen_clear.py](../tests/standalone/screen_clear.py)，清除保存的流程及开机启用策略。
5. 关闭连接后，原先启用的默认页面应恢复；再次RESET确认A/B不再运行。原先未配置默认页的设备不保证自动显示特定画面。

上述“还原”指恢复原显示策略和原配置，固件保留0.6.0，不是把整板退回旧固件。整个过程不需要erase-flash，也不需要清除全部舵机映射或重新上传默认模板。

## 为什么可以清除后继续写代码

固化流程存于独立NVS键，运行时使用自己的屏幕/舵机配置快照。Program停止后恢复原在线映射；`robot.program.clear()`只删除保存的流程和开机策略，保留原屏幕/舵机配置和pages模板。

```python
from ai_robot import Robot

with Robot(port="COM5") as robot:
    robot.program.clear()
    print(robot.program.info())
```

如果只想暂时不开机运行，可用`disable()`保留步骤；`stop()`只停本次运行，不会关闭下次开机。需要恢复测试前另一个固化流程时，先`download()`保存其program/loop/enabled，再用`Program.from_dict(...)`和save恢复；清除后不能从板端凭空找回未备份的流程。
