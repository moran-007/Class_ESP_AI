# 后续任务

当前版本先证明电脑 Python 经 USB 控制设备的本地闭环，AI 服务器不在此目录开发。

1. 补齐 GPIO、ADC、PWM 和舵机的真实接线、电平、波形、校准及断连测试，分别记录；板载灯不替代外设验收。
2. 将当前保守板级能力表拆成可验证的板级描述，加入外设驱动配置、SPI/I²S 总线共享与资源预算。开发板或模组更换必须核对实际占用。
3. V0.3已接入ST7735S/ST7789驱动、中文与图形、可保存SPI/BLK引脚、维护和资源检查；继续逐块完成7针ST7789、8针ST7789和ST7735S的实际图像、方向、颜色及背光验收，后续再考虑SPI共享。
4. V0.5已实现单麦INMP441录音、MAX98357A播放、I²S会话映射、统一AudioClip及本地/显式URL音频。继续完成用户实际接线的收音、噪声、音量和时序验收；独立存储、全双工、重采样及压缩解码仍待开发。
5. V0.4已提供本地网页页面编辑器、受限JSON页面和小图标上传、板端默认页，以及标准库Turtle和整屏图片临时传输。后续任意HTML/CSS/JS学员作品上传、隔离宿主、历史版本恢复与受限硬件桥接仍待开发，student_web能力保持false。
6. V0.4已实现页面专用有界分块、CRC和双槽保存；通用文件服务、课程权限模板仍待开发。保留可信管理和USB恢复入口。

任何阶段不以空函数、模拟成功或单纯新增目录表示功能已经实现。暂不实现云端身份、MQTT、AI 识别与模型调用。
