# SDK 跨电脑安装与直接导入

目标是“安装一次SDK，之后在任意文件夹直接 `from ai_robot import Robot` 编写程序”。原项目的 `_board`、`classroom.py`、JSON配置窗口仍是本工程教学工具，新代码不必依赖它们。

## 1. 另一台Windows电脑

准备 Python 3.11+ 和 pip。在运行课件或自己程序的 Python 环境中执行以下命令。已安装 Tcl/Tk 的 Python 可直接运行 Turtle 窗口。

```powershell
python -m pip install "ai-maker-robot[drawing] @ https://github.com/moran-007/Class_ESP_AI/releases/download/v0.9.0/ai_maker_robot-0.9.0-py3-none-any.whl"
```

pip 会从 GitHub 拉取 SDK，从包索引安装 pyserial 和 Pillow，然后把包放进所用解释器的库目录。安装后，任意目录的脚本都能用这个解释器导入 `ai_robot`。可以用下面的命令检查安装。

```powershell
python -c "import ai_robot; print(ai_robot.__version__)"
```

IDE 中选择执行安装命令时使用的 Python 解释器。只需基本 GPIO、语音和串口时，可将命令中的 `ai-maker-robot[drawing]` 改为 `ai-maker-robot`。已下载完整工程的用户可直接双击 [安装Python环境.cmd](../安装Python环境.cmd)，该入口会创建并安装项目的 `.venv`。

## 2. 离线电脑

SDK wheel是纯Python，不绑定E盘路径。pyserial也是独立依赖；Pillow带平台/解释器相关的二进制。制作离线资料时，需要在与目标电脑操作系统、Python版本、架构匹配的环境下载依赖，不能把某台Python3.14的Pillow wheel当作所有电脑通用安装包。

联网准备机可运行：

```powershell
python -m pip download --dest wheelhouse "ai-maker-robot[drawing] @ https://github.com/moran-007/Class_ESP_AI/releases/download/v0.9.0/ai_maker_robot-0.9.0-py3-none-any.whl"
```

把 wheelhouse 目录和示例复制到目标电脑。离线安装时在 wheelhouse 所在的目录运行以下命令。

```powershell
python -m pip install --no-index --find-links wheelhouse "ai-maker-robot[drawing]==0.9.0"
```

仅GPIO/舵机/音频无需Pillow，可不带drawing扩展。此说明不会声称本机已生成适用于所有Python/系统的离线依赖集合。

## 3. 最小程序

```python
from ai_robot import Robot

with Robot(port="COM5") as robot:
    print(robot.get_info())
```

COM5只是当前电脑串口名，换电脑须改成实际端口；AUTO只有一个USB候选时才自动选择，不逐个探测。可以不用with，但应以try/finally保证robot.close。原生USB音频流推荐使用开发板原生USB连接；波特率数字不代表原生USB带宽，也不能用UART115200宣称连续16kHz流实时无损。

## 4. 所有主要功能来自包内

```python
from ai_robot import Robot, AudioClip, load_audio_url, validate_project, load_project
from ai_robot.drawing import capture_turtle, send_turtle
from ai_robot.turtle import finish
```

Robot包含digital、analog、gpio、adc、pwm、servo、led、display、pages、audio。数字量只接受0/1；analog是ADC输入，analog.write明确报不支持DAC；PWM仍是独立占空比接口。原gpio/adc/pwm函数保留兼容。

音频统一使用AudioClip，不让本地与云端各自使用不兼容的字节格式：

```python
from ai_robot import AudioClip

clip = AudioClip.from_wav("recording.wav")
print(clip.to_wire())  # 元数据，不含WAV头或整段base64。
pcm = clip.to_pcm()   # 可直接用于现有16kHz/16-bit/mono PCM数据入口。
same = AudioClip.from_wire(pcm, clip.to_wire())
```

录制和本地文件音频限定为 30 秒，须使用 16 kHz 单声道 PCM。AI 对话由电脑连接网关，需要服务地址和设备凭据，参见 [AI 调用教程](开发指南.md#19-接入原-ai-服务器)。

可直接复制运行的文件见 [examples/portable](../examples/portable/README.md)。旧课程文件和本地配置功能继续保留，建议后续新增课程优先使用这个包内导入方式。
