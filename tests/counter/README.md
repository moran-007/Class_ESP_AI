# 每秒加一：真机测试入口

需要SDK及教学固件0.7.0。保存计数示例位于 [examples/portable/16_counter.py](../../examples/portable/16_counter.py)，COM5和屏幕IO都在文件里，按实际修改后直接运行。保存后关闭程序，按RESET或重新接电；板端从0开始，每秒加1，不需要电脑控制会话。电脑重新创建Robot会接管并停止，这是正常控制规则。

- `clear_counter.py`：删除保存的计数流程，保留原默认页/屏幕/舵机配置；关闭连接后恢复原先启用的默认页。
- `restore_previous.py`：只在本机存在本次私有备份时，恢复计数测试前的固化流程及loop/enabled策略；不会回退固件。备份文件默认位于backups/counter_v070_20261115/before.json，不随公开源码分发。

本次测试前实际板还有一段启用中的13步A/B流程，已先备份。清除计数和恢复此前A/B是两个不同操作，按需要运行对应文件；不要把整板擦除当成清除。

计数在RAM运行，reset从start重新计数，非断电续计；不会每秒写Flash。计数器自己持续运行，保存时保持loop=False默认值，不能另开root循环。数字区域默认144×20，只局部清除和重画，避免每秒重绘整屏。参数和限制见 [数字累加说明](../../docs/数字累加计数器_V0.7.md)。
