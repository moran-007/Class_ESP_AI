# AI 服务器测试

双击 [运行.cmd](运行.cmd) 即可运行 [ai_test.py](ai_test.py)。也可以在编辑器用项目的 .venv 运行同一个 Python 文件。脚本启动后读取已保存的本机配置，并设置串口、数字按钮和音频。第一次使用时，把 [ai.example.json](../../config/ai.example.json) 复制为 config/ai.local.json，填写服务器地址、设备 ID 和 Token。更换凭据后重开脚本，Git 会忽略这个文件。

1. 用原生 USB 连接 ESP32-S3，按脚本开头的 PORT、BUTTON_PIN 和 AUDIO_PINS 接线，电脑保持联网。
2. 看到「准备就绪」后按住按钮说话。按下调用 `robot.ai.record_start()` 采集本地音频，松开调用 `robot.ai.record_end()` 上传。服务器的回复每就绪一段，控制台打印该段文字，ESP32 功放播报该段。最后显示本轮识别到的话。
3. 等待下一条「准备就绪」再开始新一轮。按 Ctrl+C 退出并关闭串口。

PORT 默认为 AUTO，电脑上只有一个 USB 串口时会自动选择。有多个 USB 串口时，在程序开头填写开发板的 COM 号。按钮接 GPIO2 与 GND，按下为低电平。INMP441 和 MAX98357A 共用 BCLK 42、WS 41。麦克风 SD 接 GPIO21，功放 DIN 接 GPIO40，功放 SD/EN 接 GPIO39。麦克风 L/R 接 GND。模块供电、共地和 L/R 选择见 [音频接线说明](../../docs/数字模拟IO与音频测试_V0.5.md)。

默认最多录制 20 秒的音频，到达上限仍等松开再发送。少于 0.2 秒时提示重录。每轮按键最多提交一次。控制台会区分 Token 失效或 ID 不匹配、服务端明确报告额度用尽、限流、连接失败、HTTPS 连接失败和等待超时。普通任务错误可用提示中的任务号查日志。

服务器同时生成多段回复时按段号播放。下一段还未生成时会有停顿。按 Ctrl+C 可以结束电脑上的录音或播报，服务器已经接收的任务可能继续运行。
