# 屏幕固化真机测试

固件和SDK均需0.6.0。文件直接导入已安装的ai_robot，不依赖_board。改PORT和实际屏幕参数后点击运行；推荐IDE使用工程根目录`.venv/Scripts/python.exe`。

| 文件 | 行为 |
|---|---|
| screen_save.py | 将屏幕A/B循环保存到板端并启用下次开机，不立即运行 |
| screen_clear.py | 清除固化流程及其开机策略，保留原屏幕/舵机配置与页面；不是整板擦除 |

默认：ST7735S128×160，旋转1后160×128；SCK/SCL4、MOSI/SDA5、CS15、DC7、RST/RES6、BLK16。BLK若实际没有接可控GPIO，应自行按模块接法修改，不能填供电脚为IO。

操作顺序：运行screen_save → 关闭程序 → 按RESET或断电重接 → 看深蓝A/深绿B每4秒交替 → 保持电脑端没有运行Robot → 再运行screen_clear → 看原默认页恢复 → 再次RESET验证A/B不再出现。

查询program.info也会因创建Robot取得会话而接管停止，所以观察固化时不要同时运行其他Robot脚本。仅USB供电但没有Python控制会话可以验证独立执行；真正断开电脑后改电源供电，需要用户现场操作并确认，本机软件不会假称已替用户拔线。

清除的含义：删除保存流程和开机启用标志，不降级固件。若原先没有启用默认页，清除后不保证出现某个预设画面；此时需自行正常配置显示。若测试前已有重要固化流程，应先用program.download备份，测试后按原loop/enabled策略save恢复。详细步骤见 [屏幕固化与清除说明](../../docs/屏幕固化测试与清除恢复_V0.6.md)。
