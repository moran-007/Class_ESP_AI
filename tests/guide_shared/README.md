# 统一配置版短示例

先双击项目根目录 `配置硬件.cmd`，选USB串口、外部LED/按钮/ADC/PWM/舵机/屏幕GPIO，再保存。所有设置集中在 `config/hardware.json`，不需要逐个示例改PIN。保存后重新运行示例才生效。

这是可选集中配置版，请在IDE直接运行本目录Python文件；主入口 `运行示例.cmd` 运行的是相邻guide目录代码内配置版。解释器使用项目 `.venv/Scripts/python.exe`。首次运行先双击 `安装Python环境.cmd`，固件要求教学版V0.4.0；当前COM5已经安装。

| 文件 | 所需设备与效果 |
|---|---|
| `01_info.py` | 只需USB；打印设备、状态、保存配置和GPIO能力/占用 |
| `02_rgb.py` | 只需USB；板载RGB先黄后自定义颜色 |
| `03_led.py` | 外接LED与限流电阻；按led预设GPIO亮灭 |
| `04_button_led.py` | 按钮接button GPIO/GND，LED接led GPIO；按下亮、松开灭，持续15秒 |
| `05_adc.py` | 合规3.3V域模拟信号接adc GPIO并共地；读取原始计数 |
| `06_pwm.py` | LED与限流电阻接pwm GPIO/GND；1kHz占空比调光 |
| `07_servo.py` | 舵机信号按servo.pin，匹配的独立电源并共地；保存校准后立即发送90°，首次卸下连杆 |
| `08_screen.py` | 按统一配置接ST7735S/ST7789；中文、矩形与线段 |
| `09_pages.py` | 配置并初始化屏幕；上传160×128示例页面、更新状态文字；新上传关闭旧开机页，不自动再启用 |
| `10_turtle.py` | 标准库Turtle电脑画图，点击发送才连接并配置屏幕 |
| `11_image.py` | Pillow绘制圆形并等比适配整屏，显示10秒 |

每次只运行一项。03～09、11的运行表示已完成接线；会退出维护并使用相关输出。关闭会话停止临时输出；启用默认页时恢复该页。舵机信号释放不等于切断电源。当前保存的屏幕/舵机映射仍占用对应引脚，普通GPIO若冲突会报错，需先检查 `list_pins()`。

这些是新示例；`tests/quick/01`～`08` 中原有手写 `PIN` 保持原样，只有串口及屏幕公共入口已读取统一配置。新目录的 `_board.py` 负责导入位置，`classroom.py` 负责连接，学员通常无需修改它们。

参考：[统一配置说明](../../docs/统一配置与接线说明.md)、[全部SDK函数与示例](../../docs/SDK函数说明与示例_V0.4.md)。不包含已实现的AI识别/聊天函数；这类能力仍为false。
