# 简易测试：打开 Python 文件，点击运行

当前推荐新的统一配置版 [tests/guide](../guide/README.md)。旧settings.py与_screen_settings.py已改为兼容读取，请用根目录 `配置硬件.cmd`；旧01～08中的手写PIN保留。

V0.4新增页面与标准库Turtle。双击根目录 `打开页面编辑器.cmd` 制作页面，或运行本目录 `turtle_demo.py` 画图后点击“发送到 ESP32”（Enter也可）。需要Pillow，安装入口已包含；窗口关闭后恢复已启用的板端默认页。完整流程见 [页面与Turtle说明](../../docs/页面编辑器与Turtle_V0.4.md)。

| 新文件 | 用途 |
|---|---|
| `turtle_demo.py` | 真实标准库Turtle电脑窗口，短脚本，完成后发送画布 |
| `pages_upload.py` | 上传示例页面与笑脸图标，显示5秒，不启用开机显示 |
| `pages_show.py` | 显示板端已保存页面 |
| `pages_startup.py` | 启用已保存默认页，关闭连接/复位后显示 |
| `pages_startup_off.py` | 关闭自动默认页 |

上传示例页面前先运行屏幕测试保存配置。示例页面是160×128横屏；其他屏幕尺寸可用网页编辑器重新布局，上传与当前旋转后尺寸匹配的页面。只关闭网页标签页不会断开后台串口，请点击编辑器“断开连接”。

V0.3新增屏幕测试，先通过根目录 `配置硬件.cmd` 修改屏幕型号和所有实际信号引脚，再运行 `screen_colors.py`（纯色）、`screen_text.py`（中文与图形）或 `screen_backlight.py`（有GPIO背光时）。7/8针ST7789与ST7735S共用一套固件，换线后改配置即可；完整接线与步骤见 [屏幕说明](../../docs/屏幕测试与自定义引脚_V0.3.md)。

这些文件供你接线后逐项测试，不需要 `--port`、`--run` 或命令行参数。用 VS Code、PyCharm、IDLE 等打开一个文件，点击“运行”即可。运行前安装本项目 Python 依赖并烧入 `ai-maker-s3` 教学固件；常亮白灯的 `ai-maker-led-diagnostic` 是独立诊断程序，不能使用教学 SDK。

当前固件 **V0.4.0** 保留V0.2.1原生USB舵机配置超时修复。SG90 可直接运行本目录 **servo_sg90.py**：默认信号 GPIO14，脉宽配置 1000～2000µs，依次发送 60°、90°、120°、90°，每次保持一秒后结束释放信号。脚本会保存名为 test 的舵机映射，执行时须先完成供电、共地和接线；脉宽仍须按实际舵机校准。原有 07 和学员自行修改的内容保持原样。

默认在唯一 USB 串口上连接。如果电脑同时接了多个 USB 串口，在根目录配置窗口选择串口，或修改 `config/hardware.json` 的 `connection.port` 为 `"COM5"`。一次运行一个文件，并关闭 Arduino 串口监视器。示例直接引用项目内 SDK 源码，移动本目录时也须保留项目目录结构。

| 文件 | 用途 | 接线与运行结果 |
|---|---|---|
| `01_device_info.py` | 查询设备、状态、引脚能力与占用 | 仅 USB；打印当前固件信息 |
| `02_rgb.py` | 板载 RGB | 仅 USB；红、绿、蓝各 2 秒，退出熄灭 |
| `03_gpio.py` | 普通数字输出 | 默认 GPIO12，外部 LED 串限流电阻接 GND；高低电平交替 |
| `04_button.py` | 外部按钮输入 | 默认 GPIO2，按钮另一端接 GND；内部上拉，按下 0、松开 1，读 10 秒 |
| `05_adc.py` | 模拟输入 | 默认 GPIO1，与信号源共地；读取 10 次 0～4095 原始计数 |
| `06_pwm.py` | PWM 调光 | 默认 GPIO12，LED 串限流电阻接 GND；1kHz，占空比从 0 到 100% |
| `07_servo.py` | 单舵机 | 默认信号 GPIO12，`ANGLE = 90`；匹配舵机的独立电源并共地，保持 3 秒后释放信号 |
| `08_clear_servos.py` | 清除全部舵机映射 | 停止运行输出、删除保存的全部舵机映射，恢复普通 GPIO 实验 |

03～07 开头的 `PIN` 是唯一要按接线修改的参数；舵机还可修改 `ANGLE`，示例允许 30～150°。模拟信号须处于开发板允许的输入范围，不得输入 5V；ADC 原始计数未经电压校准。舵机不得从 GPIO 或开发板 3.3V 稳压器直接供电。首次测试卸下连杆，按舵机规格调整脉宽校准后再接负载。

`07_servo.py` 会保存名为 `test` 的舵机映射，然后明确退出维护并移动。该示例必须在接线、供电和校准确认后运行。退出时仅停止脉冲，电源不会被切断，映射也会保留；随后运行 GPIO/PWM 示例如遇 `RESOURCE_CONFLICT`，先运行 `08_clear_servos.py`。原有其他名称的舵机映射不会被 07 自动删除；它们占用同一引脚时应检查配置，再决定是否运行 08。

换线前先进入维护并确认输出已停，再断电换线。不要在示例运行中移动杜邦线。正常结束、Ctrl+C 或异常均关闭会话、释放输出；强制结束 Python 时，固件在约 6 秒租约到期后尝试释放。故障回执不等于已完成物理动作，RGB 颜色与外设状态仍需观察实物。

## 自己写最短程序

### 按钮控制外部 LED

直接打开本目录 `button_external_led.py` 点击运行（保留原有 04 文件供自行修改）。按钮接 GPIO2 与 GND；LED 接法为 `GPIO12 → 330Ω限流电阻 → LED正极，LED负极 → GND`。内部上拉使按钮按下读 0、松开读 1，因此程序将读数取反，按下输出 1、松开输出 0。脚本持续运行，Ctrl+C 或 IDE 停止按钮退出。

这是普通外部 LED 接法；低电平触发的灯模块或接到电源正端的 LED 电路，点亮电平可能相反。若完全不亮，先运行 `03_gpio.py` 单独验证 LED，检查极性、电阻、共地与实际接线是否为标注的 GPIO12。普通 GPIO 读回输出指令值不能证明 LED 实际已发光。GPIO12 若被保存的舵机映射占用，会明确报资源冲突，先查 01 配置，再按需处理映射。

### 自定义 RGB 程序

把下面代码保存为本目录中的新 `.py` 文件，直接运行：

```python
from _board import connect

with connect() as robot:
    robot.led.color("white")
    robot.wait(3)
```

`with` 这一层负责结束时关闭设备，SDK 在等待期间自动发送心跳。`robot.led.color()` 支持 `red`、`green`、`blue`、`yellow`、`white`、`off`，默认每通道亮度 16，可加 `brightness=8`，允许 0～32。需要混色时仍可用 `robot.led.set(red=16, green=8, blue=0)`。

屏幕驱动已在V0.3接入；麦克风、功放和网页上传尚未接入。屏幕SPI没有图像反馈，收到成功回执后仍须观察实际画面。
