# 代码内配置版短示例

直接在当前Python文件中填写 `connect("COM5")` 和外设配置调用的GPIO。推荐顺序是连接串口 → set所有IO → start → 执行动作，不需要先学习JSON或配置窗口。完整介绍见 [代码内配置与最小示例](../../docs/代码内配置与最小示例.md)。

双击 `运行示例.cmd`（旧 `运行配置示例.cmd` 入口也可） 选择一项，或在IDE直接运行本目录Python文件。解释器使用项目 `.venv/Scripts/python.exe`。首次运行先双击 `安装Python环境.cmd`，固件要求教学版V0.4.0；当前COM5已经安装。

| 文件 | 所需设备与效果 |
|---|---|
| `01_info.py` | 只需USB；打印设备、状态、保存配置和GPIO能力/占用 |
| `02_rgb.py` | 只需USB；板载RGB先黄后自定义颜色 |
| `03_led.py` | 外接LED与限流电阻；按本文件GPIO亮灭 |
| `04_button_led.py` | 按钮接button GPIO/GND，LED接led GPIO；按下亮、松开灭，持续15秒 |
| `05_adc.py` | 合规3.3V域模拟信号接adc GPIO并共地；读取原始计数 |
| `06_pwm.py` | LED与限流电阻接pwm GPIO/GND；1kHz占空比调光 |
| `07_servo.py` | 舵机信号按本文件pin，匹配的独立电源并共地；保存校准后立即发送90°，首次卸下连杆 |
| `08_screen.py` | 按本文件参数接ST7735S/ST7789；中文、矩形与线段 |
| `09_pages.py` | 配置并初始化屏幕；上传160×128示例页面、更新状态文字；新上传关闭旧开机页，不自动再启用 |
| `10_turtle.py` | 标准库Turtle电脑画图，点击发送才连接并配置屏幕 |
| `11_image.py` | Pillow绘制圆形并等比适配整屏，显示10秒 |
| `12_multi_parts.py` | 无with：屏幕+SG90+按钮+RGB，同一次连接，try/finally关闭 |
| `13_display_fps.py` | 位置参数设置IO，发送10帧图片并测电脑端完成速度；不是面板扫描率 |
| `14_turtle_top_setup.py` | 开头Robot/set/start，之后绘图，finish复用同一连接，关窗统一关闭 |

新set/start示例需要SDK0.4.1（本机两个环境已更新），固件仍为0.4.0；无需重刷。丝印别名和位置顺序见 [set与刷新帧率说明](../../docs/set接口_丝印对照与刷新帧率.md)。

每次只运行一项。03～09、11的运行表示已完成接线；会退出维护并使用相关输出。关闭会话停止临时输出；启用默认页时恢复该页。舵机信号释放不等于切断电源。当前保存的屏幕/舵机映射仍占用对应引脚，普通GPIO若冲突会报错，需先检查 `list_pins()`。

统一配置方式仍可选，原示例保存在 `tests/guide_shared/`；这些是新的代码内配置示例；`tests/quick/01`～`08` 中原有手写 `PIN` 保持原样，只有串口及屏幕公共入口已读取统一配置（可选，不影响当前显式参数）。新目录的 `_board.py` 负责导入位置，`classroom.py` 负责连接，学员通常无需修改它们。
