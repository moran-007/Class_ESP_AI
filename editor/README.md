# 本地页面编辑器

> 配置入口已统一：使用项目根目录 `配置硬件.cmd` 或 `config/hardware.json`。旧settings.py和_screen_settings.py只作兼容读取；下文相关旧配置操作以 `docs/统一配置与接线说明.md` 为准。

双击项目根目录 `打开页面编辑器.cmd`，浏览器打开 `http://127.0.0.1:8765/`。使用项目 `.venv`；未安装环境时先运行根目录的安装脚本。也可从项目根目录执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\start_page_editor.py
```

仅做离线设计时不需要连接开发板。网页文件、字体选择与图标转换均在本机完成，没有CDN和AI服务器。关闭浏览器标签页不会结束后台Python进程，也不会断开USB；请点击网页“断开”，或在编辑器控制台按Ctrl+C，才会关闭会话并由板端按开机显示设置恢复。

## 操作顺序

1. 选择与屏幕旋转后尺寸相同的画布，例如ST7735S横屏160×128。
2. 选择页面，添加文字、矩形、线段或图标；在画布中拖动，在右侧修改坐标、颜色与文字。
3. 可随时导出JSON保存到电脑。页面包包括所有小图标，不需要另行拷贝图片。
4. 需要实机显示时选择USB串口并点击“连接开发板”。此时才建立USB控制会话，临时接管板端默认页。
5. 展开“屏幕型号与自定义引脚”，核对真实接线。首次或换线后点击“保存屏幕接线”；它保存配置并退出维护，但不初始化屏幕。
6. 点击“保存页面包并显示”。拖拽、文字编辑和电脑预览都不会写Flash。画布尺寸与板端屏幕不一致时会明确报错；接线不会被页面上传自动改写。
7. 勾选“断开电脑后显示当前页”并保存开机设置后，点击“断开”，默认页由ESP32继续显示；重启后由板端加载。禁用开机显示不依赖电脑画布里的页面ID是否已上传。

“显示已保存的当前页”仅切换板上保存的版本；未保存的电脑修改不会自动生效。“读取开发板页面包”会将保存包载入电脑编辑器。

## 页面和图片边界

- 页面最多4个，总组件最多32个，图片最多4张，紧凑UTF8 JSON最多8192字节。
- 图片每边最多48像素，全部RGB565像素数据最多4608字节。
- 导入PNG/JPEG/WebP后按所选最大边长缩小，透明部分合成到当前背景；转换为RGB565大端像素并嵌入JSON。不接受SVG或网页脚本。
- 中文预览使用电脑字体，板端使用12px文泉驿字体，因此字形与字宽预览可能有细微差异；实际显示以屏幕为准。
- 页面包只含数据，不包含可执行Python、JavaScript或GPIO动作。

## Wi-Fi 配网

连接声明 `wifi_provisioning` 的 0.8 教学固件，展开「开发板 Wi-Fi 配网」。输入 2.4 GHz 网络名称（支持中文）和密码，点「连接并保存」。页面显示试连状态、最终 IPv4 或失败原因。「查看状态」查询板端状态，「清除配网」只移除 Wi-Fi 设置。网页后台保持只监听本机。终端方式和现有板兼容限制见 [开发指南](../docs/开发指南.md#18-usb-wi-fi-配网)。

## 本地服务

仅监听127.0.0.1；API需要当前页面的随机会话token、合法Host及同源请求，不提供CORS。刷新页面可获取当前服务token；重启服务后旧标签页需要刷新。服务关闭时会关闭其持有的Robot连接。

开发或验证时可不自动打开浏览器，或使用其他端口：

```powershell
.\.venv\Scripts\python.exe .\scripts\start_page_editor.py --no-browser --port 8766
.\.venv\Scripts\python.exe -m unittest discover -s .\editor\tests -v
```

后端测试使用FakeRobot和真实本地HTTP请求，不接触真实串口。浏览器验证截图保存在项目的`output/playwright/`下。
